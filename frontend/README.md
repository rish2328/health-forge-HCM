Steps to Setup::

## Basic Project Setup
1.  node -v (22 or 22+)
2.  npm -v (10.* or 10+)
3.  npm create vite@latest healthcare-frontend
    Select:
        →   Select a framework:                 →   React
        →   Select a variant:                   →   JavaScript
        →   Which linter to use?                →   ESLint
        →   Install with npm and start now?     →   Yes

4.  npm install
5.  npm run dev

## Required Packages Installation
npm install axios react-router-dom @mui/material @emotion/react @emotion/styled @mui/icons-material react-hook-form yup @hookform/resolvers react-toastify
```bash
| Package             | Purpose               |
| ------------------- | --------------------- |
| axios               | API Calling           |
| react-router-dom    | Routing               |
| Material UI         | UI Components         |
| @mui/icons-material | Icons                 |
| react-hook-form     | Form Handling         |
| yup                 | Validation            |
| @hookform/resolvers | React Hook Form + Yup |
| react-toastify      | Notifications         |
```
